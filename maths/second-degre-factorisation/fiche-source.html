FICHE DE RÉVISION

Équations du second degré — partie 3 : Factorisation et signe d'un trinôme  •  ax² + bx + c  (a ≠ 0)

1. LA FORME FACTORISÉE
y = a(x − x₁)(x − x₂)
Les solutions x₁ et x₂ se lisent directement.
⚠️ (x − 2) → racine +2 ; (x + 3) → racine −3.
N'existe que si Δ ≥ 0 (la courbe touche l'axe).
2. LA RÈGLE DU PRODUIT NUL
Un produit est nul si et seulement si l'un de ses facteurs est nul.
(x − 2)(x + 5) = 0 → x − 2 = 0 ou x + 5 = 0
→ x = 2 ou x = −5. Pas de Δ, pas de formule !
3. FACTORISER : LA MÉTHODE
① Racines x₁, x₂ avec Δ (partie 2)  ② Écrire a(x − x₁)(x − x₂) — sans oublier le a !
Exemple : 2x² − 2x − 12 : Δ = 4 + 96 = 100,
x₁ = −2, x₂ = 3 → 2(x + 2)(x − 3)
Vérif : développe, tu retombes dessus ✓
4. ET SANS DEUX RACINES ?
Δ = 0 : racine double → factorisation a(x − x₀)².
Le signe est celui de a partout (0 seulement en x₀).
Δ < 0 : pas de racines → pas de factorisation,
et le trinôme est du signe de a partout. Jamais de changement de signe !
5. LE SIGNE DU TRINÔME (LA RÈGLE D'OR)
Signe de a à l'extérieur des racines, signe opposé entre les racines (et 0 pile sur chaque racine) :
a > 0 😊
x−∞x₁x₂+∞
y+0−0+
a < 0 ☹️
x−∞x₁x₂+∞
y−0+0−
6. EXEMPLE : x² − x − 6 ≤ 0
Racines : −2 et 3 (Δ = 25) → (x + 2)(x − 3)
a = 1 > 0 → négatif entre les racines
S = [−2 ; 3] (bornes incluses car « ≤ »)
Pour « ≥ 0 » : l'extérieur → S = ]−∞ ; −2] ∪ [3 ; +∞[
7. LES PIÈGES À ÉVITER
  • (x + 3) s'annule en x = −3, pas +3 !
  • Le a devant la factorisation s'oublie facilement.
  • Solution d'une inéquation = un intervalle, pas deux nombres.
  • Bornes incluses avec ≤ / ≥, exclues avec < / >.
8. LES 3 ÉCRITURES D'UN MÊME TRINÔME (récap du chapitre)
ax² + bx + c
développée — on lit c (hauteur en x = 0)
a(x − α)² + β
canonique — on lit le sommet (α ; β)
a(x − x₁)(x − x₂)
factorisée — on lit les solutions
