🧮 Chapitre : Équations du second degré

🚦 Factorisation et signe d'un trinôme

Dernière partie du chapitre ! Une troisième écriture de la parabole — celle qui montre les solutions directement — puis un super-pouvoir : savoir si le trinôme est positif ou négatif, partout, sans calculer. Ta première inéquation t'attend au bout.

Étape 1

Une 3ᵉ écriture : la forme factorisée 🧩

Tu connais déjà deux façons d'écrire une parabole : la forme développée ax² + bx + c (partie 1) et la forme canonique a(x − α)² + β qui montre le sommet. Quand la parabole traverse l'axe horizontal (Δ > 0), il en existe une troisième, et c'est la plus bavarde de toutes :

y = a(x − x₁)(x − x₂)   ⟶   les solutions x₁ et x₂ se lisent directement !

Déplace les curseurs : tu tiens la parabole… par ses deux racines !

⚠️ Le piège des signes (le même qu'avec la forme canonique) : dans (x − 2), la racine est +2. Dans (x + 3), la racine est −3, car x + 3 = x − (−3). Le facteur s'annule quand x vaut l'opposé du nombre écrit après le +.
Étape 2

Pourquoi ça marche : la règle du produit nul

Toute la magie de la forme factorisée repose sur une idée toute simple. Multiplie deux nombres : quand est-ce que le résultat vaut 0 ?

Un produit est nul si, et seulement si, l'un de ses facteurs est nul.

3 × 5 ≠ 0,   (−7) × 2 ≠ 0… mais 0 × n'importe quoi = 0. Il n'y a pas d'autre moyen d'obtenir 0 ! Du coup, résoudre une équation factorisée est un jeu d'enfant :

Exemple : résoudre (x − 2)(x + 5) = 0.
Le produit est nul si x − 2 = 0 (donc x = 2) ou si x + 5 = 0 (donc x = −5).
Solutions : x = 2 ou x = −5. Pas de Δ, pas de formule, rien. 🎉
💡 C'est exactement l'astuce du « cas rapide c = 0 » de la partie 2 : 3x(x + 2) = 0 → x = 0 ou x = −2. La forme factorisée, c'est cette astuce généralisée à toutes les paraboles qui coupent l'axe.
Étape 3

Factoriser un trinôme : la méthode 🛠️

Comment passer de ax² + bx + c à la forme factorisée ? On utilise ce qu'on sait déjà faire depuis la partie 2 : trouver les racines !

Méthode : ① calcule Δ et les racines x₁, x₂ (partie 2)  →  ② écris a(x − x₁)(x − x₂) — sans oublier le a devant !

Exemple : factoriser 2x² − 2x − 12.
Δ = (−2)² − 4 × 2 × (−12) = 4 + 96 = 100,   √Δ = 10
x₁ = (2 − 10)/4 = −2    x₂ = (2 + 10)/4 = 3
Donc 2x² − 2x − 12 = 2(x + 2)(x − 3).  (Vérifie en développant !)
⚠️ Deux cas particuliers : si Δ = 0, la factorisation est a(x − x₀)² (le facteur apparaît deux fois). Si Δ < 0, pas de racines… donc pas de factorisation possible (avec les nombres qu'on connaît).

Étape 4

Le signe du trinôme : positif où ? négatif où ? 🚦

Nouvelle question : sans chercher les valeurs exactes de y, peut-on savoir où la courbe est au-dessus du sol (y positif, en vert) et où elle est en dessous (y négatif, en rouge) ? Regarde les zones colorées et bouge les curseurs :

💡 La règle d'or (à retenir par cœur, elle tombe tout le temps) : le trinôme est du signe de a à l'extérieur des racines, et du signe opposé entre les racines. Ça se voit : loin des racines, la parabole part vers le haut si a > 0 (positif) ou vers le bas si a < 0 (négatif). Entre les deux, elle a forcément traversé le sol !

Étape 6

Application : ta première inéquation 🏆

Une inéquation, c'est comme une équation, mais avec ≤ ou ≥ au lieu de = : on ne cherche plus où y vaut 0, mais où y est négatif (ou positif). Résolvons ensemble :

x² − x − 6 ≤ 0
  1. Étape 1 — On traduit.
    On cherche tous les x pour lesquels y = x² − x − 6 est négatif ou nul : les endroits où la parabole est au niveau du sol ou en dessous.
  2. Étape 2 — On trouve les racines.
    Bonne nouvelle : on les connaît déjà (c'est l'exemple de la partie 2) ! Δ = 25, x₁ = −2 et x₂ = 3. Donc x² − x − 6 = (x + 2)(x − 3).
  3. Étape 3 — On applique la règle du signe.
    Ici a = 1 > 0 : le trinôme est positif à l'extérieur des racines, négatif entre elles. C'est donc entre −2 et 3 que y ≤ 0.
  4. Étape 4 — On conclut (et on regarde ! 👇)
    Les solutions sont tous les x de −2 à 3, bornes comprises (car en −2 et 3, y = 0, et « ≤ 0 » accepte le 0). On écrit : S = [−2 ; 3].
💡 Remarque la nouveauté : la solution d'une équation, c'est quelques nombres (x = −2 ou x = 3). La solution d'une inéquation, c'est tout un intervalle — une infinité de nombres d'un coup ! Si l'inéquation avait été « ≥ 0 », on aurait pris l'extérieur : S = ]−∞ ; −2] ∪ [3 ; +∞[.
Étape 7

Petit quiz pour vérifier 🎓

1. Les solutions de 2(x − 1)(x + 4) = 0 sont…

✅ (x − 1) s'annule pour x = 1, (x + 4) s'annule pour x = −4. Le piège : inverser les signes ! (Et le 2 devant n'est jamais nul, il ne donne pas de solution.)

2. Un produit de deux facteurs est nul…

✅ 0 × n'importe quoi = 0 : un seul facteur nul suffit. Et c'est le seul moyen d'obtenir 0 avec une multiplication.

3. x² − x − 6 = (x + 2)(x − 3). Ce trinôme est négatif…

✅ a = 1 > 0, donc signe de a (positif) à l'extérieur des racines, négatif entre −2 et 3. (Attention : c'est le trinôme entier qui compte, pas juste le x² !)

4. Si Δ < 0, le signe du trinôme ax² + bx + c est…

✅ Δ < 0 : la parabole ne traverse jamais le sol, donc elle reste entièrement du même côté — celui indiqué par a (en haut si a > 0, en bas si a < 0).

5. La forme factorisée de x² − 9 est…

✅ Les racines de x² − 9 = 0 sont x = 3 et x = −3 (cas rapide b = 0 !), donc x² − 9 = (x − 3)(x + 3). Tu la reconnais peut-être : c'est l'identité remarquable a² − b².
Récap

Ce qu'il faut retenir 📌

1. La forme factorisée

y = a(x − x₁)(x − x₂) : les solutions x₁ et x₂ se lisent directement (attention aux signes !).

2. Le produit nul

Un produit est nul si et seulement si l'un de ses facteurs est nul.

3. Factoriser

Racines via Δ, puis a(x − x₁)(x − x₂). Δ = 0 → a(x − x₀)². Δ < 0 → impossible.

4. Le signe

Signe de a à l'extérieur des racines, signe opposé entre elles. Sans racines : signe de a partout.

5. Les 3 écritures

Développée → on lit c. Canonique → on lit le sommet. Factorisée → on lit les solutions.
