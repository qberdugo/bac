FICHE DE RÉVISION

Équations du second degré — partie 1 : Forme canonique et variations  •  y = ax² + bx + c  (a ≠ 0)

1. LA COURBE : UNE PARABOLE
y = ax² + bx + c se dessine en parabole.
a > 0 : elle « sourit » 🙂
a < 0 : elle « boude » 🙁
c = hauteur de la courbe quand x = 0.
Si a = 0 : plus de x², plus de parabole !

2. FORME CANONIQUE ET SOMMET
y = a(x − α)² + β
Le sommet se lit directement : (α ; β).
Pour le retrouver depuis a, b, c :
α = −b2a   puis   β = y quand x = α.
4. TROUVER LE SOMMET : LA MÉTHODE
  1. 1 Calculer  α = −b2a  (b avec son signe !)
  2. 2 Calculer β : remplacer x par α dans y
  3. 3 Signe de a → β est un minimum (a > 0) ou un maximum (a < 0)
5. EXEMPLE : y = x² − 6x + 1
a = 1,  b = −6,  c = 1
α = −b / 2a = −(−6) / 2 = 3
β = 3² − 6 × 3 + 1 = 9 − 18 + 1 = −8
Sommet : (3 ; −8).  a = 1 > 0 → la courbe sourit :
y décroît ↘ jusqu'au minimum −8, puis croît ↗ ✓
6. LES PIÈGES À ÉVITER
  • (x − 3)² → α = +3  /  (x + 3)² → α = −3
  • Dans α = −b/2a, b garde son signe : b = −6 → α = +3
  • Ne confonds pas c (hauteur en x = 0) et β (hauteur du sommet)
  • a = 0 interdit : sans x², plus de parabole !
