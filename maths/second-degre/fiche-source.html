FICHE DE RÉVISION

Les équations du second degré  •  ax² + bx + c = 0  (a ≠ 0)

1. LA COURBE : UNE PARABOLE
y = ax² + bx + c se dessine en parabole.
a > 0 : elle « sourit » 🙂
a < 0 : elle « boude » 🙁
c = hauteur de la courbe quand x = 0.
Si a = 0 : plus de x², plus de parabole !
2. FORME CANONIQUE ET SOMMET
y = a(x − α)² + β
Le sommet se lit directement : (α ; β).
Pour le retrouver depuis a, b, c :
α = −b / 2a   puis   β = y quand x = α.
3. LE DISCRIMINANT : LE DÉTECTEUR DE SOLUTIONS
Δ = b² − 4ac   Son signe dit combien de fois la parabole traverse l'axe horizontal :
Δ > 0
2 solutions
Δ = 0
1 solution
Δ < 0
0 solution
4. LES SOLUTIONS (si Δ ≥ 0)
x = −b ± √Δ2a
Si Δ = 0 : une seule solution  x = −b / 2a  (le sommet !)
5. LA MÉTHODE EN 4 ÉTAPES
  1. 1 Identifier a, b, c (AVEC leurs signes !)
  2. 2 Calculer Δ = b² − 4ac
  3. 3 Regarder le signe de Δ → 2, 1 ou 0 solution(s)
  4. 4 Si Δ ≥ 0, appliquer la formule  x = (−b ± √Δ) / 2a
6. EXEMPLE : x² − x − 6 = 0
a = 1,  b = −1,  c = −6
Δ = (−1)² − 4×1×(−6) = 1 + 24 = 25 > 0 → 2 solutions
√Δ = √25 = 5
x₁ = (1 − 5)/2 = −2    x₂ = (1 + 5)/2 = 3
Vérif : 3² − 3 − 6 = 0 ✓
7. LES PIÈGES À ÉVITER
  • b et c gardent leur signe :
    dans 3x² − 5x + 2, b = −5 (pas 5 !)
  • (x − 3)² → α = +3  /  (x + 3)² → α = −3
  • x² = 4 a DEUX solutions : x = 2 et x = −2
  • Toujours vérifier en remplaçant x !
