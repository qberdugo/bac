🧮 Chapitre : Équations du second degré

🎯 Résolution d'une équation du second degré

Dans la partie 1, on a laissé une question en suspens : à quelle distance le ballon retombe-t-il ? Voici la partie où on apprend à répondre — avec le discriminant, la fameuse formule… et quelques raccourcis malins.

Étape 1

La question laissée en suspens 🏀

Souviens-toi de la partie 1 : la trajectoire du ballon est une parabole, d'équation y = −0,05x² + 0,9x + 2. Le ballon touche le sol quand sa hauteur y vaut 0. La question « où retombe-t-il ? » se traduit donc en maths par :

−0,05x² + 0,9x + 2 = 0
👀 On voit sur le dessin que la courbe traverse le sol quelque part vers la droite… mais où exactement ? À la fin de cette partie, tu sauras le calculer au centimètre près, sans dessin. C'est ça, résoudre une équation du second degré.
Étape 2

Résoudre = trouver où la courbe traverse le sol

Résoudre l'équation ax² + bx + c = 0, c'est chercher les valeurs de x pour lesquelles y vaut 0. Sur le dessin, c'est ultra concret : ce sont les endroits où la parabole coupe l'axe horizontal (le « sol »). Fais glisser la parabole de haut en bas avec le curseur :

🎯 Tu viens de découvrir la chose la plus importante du chapitre : une équation du second degré peut avoir 2 solutions (la courbe traverse le sol en deux points), 1 seule solution (elle touche le sol du bout de son nez… exactement par son sommet !) ou 0 solution (elle flotte sans jamais toucher le sol). Il n'y a pas d'autre cas possible !
Étape 3

Le discriminant Δ : un détecteur de solutions

Question : peut-on savoir sans dessiner combien il y a de solutions ? Oui ! Il existe un « détecteur » qui se calcule avec a, b et c. On l'appelle le discriminant et on le note Δ (la lettre grecque « delta ») :

Δ = b² − 4ac

Bouge les curseurs : à chaque position, on calcule Δ et on regarde la courbe. Vérifie que le signe de Δ prédit toujours correctement le dessin !

Δ > 0

La courbe traverse le sol : 2 solutions.

Δ = 0

La courbe touche juste le sol : 1 solution.

Δ < 0

La courbe ne touche jamais le sol : 0 solution.

Étape 4

La formule qui donne les solutions

Le discriminant dit combien il y a de solutions. Mais pour savoir lesquelles, il existe une formule magique. Quand Δ ≥ 0, les solutions sont :

x = −b ± √Δ2a

Le symbole ± veut dire « une fois avec +, une fois avec − » : c'est ce qui donne les deux solutions. Voyons-la fonctionner pas à pas sur un exemple : résolvons x² − x − 6 = 0. Clique sur le bouton pour dérouler chaque étape.

  1. Étape 1 — On identifie a, b, c.
    Dans x² − x − 6 :   a = 1 (devant x²),   b = −1 (devant x),   c = −6 (le nombre seul). Attention aux signes moins, ils font partie du nombre !
  2. Étape 2 — On calcule Δ.
    Δ = b² − 4ac = (−1)² − 4 × 1 × (−6) = 1 + 24 = 25. Comme Δ > 0, il y a 2 solutions. 🎉
  3. Étape 3 — On calcule √Δ.
    √25 = 5 (car 5 × 5 = 25).
  4. Étape 4 — On applique la formule.
    x₁ = (−b − √Δ) / 2a = (1 − 5) / 2 = −4/2 = −2
    x₂ = (−b + √Δ) / 2a = (1 + 5) / 2 = 6/2 = 3
  5. Étape 5 — On vérifie sur le graphique ! 👇
    La parabole y = x² − x − 6 coupe bien le sol en x = −2 et x = 3. La formule et le dessin racontent la même histoire.
💡 Petite vérification que tu peux toujours faire : remplace x par la solution dans l'équation. Ici : 3² − 3 − 6 = 9 − 3 − 6 = 0 ✅. Ça marche !
Étape 5

Les cas rapides : quand b ou c vaut 0 ⚡

La formule avec Δ marche toujours. Mais dans deux situations très fréquentes, il y a plus rapide — et les profs adorent les mettre en contrôle pour voir si tu réfléchis avant de calculer !

🟦 Pas de « x » tout seul (b = 0)

Exemple : 2x² − 18 = 0. On isole x² comme dans une équation ordinaire :

2x² = 18  →  x² = 9  →  x = 3 ou x = −3

⚠️ Ne pas oublier la solution négative : deux nombres opposés ont le même carré !

🟩 Pas de nombre tout seul (c = 0)

Exemple : 3x² + 6x = 0. On met x en facteur :

3x(x + 2) = 0  →  x = 0 ou x = −2

💡 Un produit est nul seulement si l'un de ses facteurs est nul. (Garde cette idée en tête : c'est la star de la partie 3 !)

⚠️ Et si on tombe sur x² = −9 ? Aucune solution ! Un carré n'est jamais négatif. C'est cohérent avec le discriminant : ici Δ = 0² − 4 × 1 × 9 = −36 < 0.

Étape 7

Le grand final : où retombe le ballon ? 🏀

Tu as maintenant tout ce qu'il faut pour répondre à la question de la partie 1. Résolvons −0,05x² + 0,9x + 2 = 0 ensemble, étape par étape :

  1. Étape 1 — On identifie a, b, c.
    a = −0,05   b = 0,9   c = 2. (Oui, a peut être un petit nombre à virgule — la méthode ne change pas !)
  2. Étape 2 — On calcule Δ.
    Δ = b² − 4ac = (0,9)² − 4 × (−0,05) × 2 = 0,81 + 0,4 = 1,21. Δ > 0 : deux solutions.
  3. Étape 3 — On calcule √Δ.
    √1,21 = 1,1 (car 1,1 × 1,1 = 1,21).
  4. Étape 4 — On applique la formule (attention, 2a = −0,1 est négatif !).
    x₁ = (−0,9 − 1,1) / (−0,1) = (−2) / (−0,1) = 20
    x₂ = (−0,9 + 1,1) / (−0,1) = 0,2 / (−0,1) = −2
  5. Étape 5 — On interprète !
    Deux solutions mathématiques : x = 20 et x = −2. Mais x = −2, c'est… 2 mètres derrière la joueuse 😄. La courbe traverse aussi le sol de ce côté-là, mais le ballon, lui, part vers l'avant. La vraie réponse est donc : le ballon retombe à 20 mètres. 👇
🌟 Retiens ce réflexe : quand une équation vient d'un problème concret, il faut toujours se demander si les solutions ont un sens dans la situation. Ici, la solution −2 est correcte en maths, mais absurde pour le ballon : on la met de côté en l'expliquant.
Étape 8

Petit quiz pour vérifier 🎓

1. Sur un graphique, les solutions de ax² + bx + c = 0, c'est…

✅ Exactement : résoudre l'équation, c'est chercher où y = 0, donc où la courbe traverse le « sol ».

2. Si Δ < 0, l'équation a…

✅ Δ négatif = la parabole ne touche jamais l'axe horizontal, donc aucune solution.

3. Dans l'équation 3x² − 5x + 2 = 0, que vaut b ?

✅ b est le nombre devant x, avec son signe : ici b = −5. Le piège classique, c'est d'oublier le moins !

4. Pour x² − 4 = 0, on a Δ = 0² − 4 × 1 × (−4) = 16. Les solutions sont…

✅ x = (0 ± √16)/2 = ±4/2 = ±2. Et ça se comprend sans formule : x² = 4, donc x = 2 ou x = −2 (deux nombres opposés ont le même carré — souviens-toi de la partie 1 !). C'est d'ailleurs un « cas rapide » : b = 0.

5. Si Δ = 0, l'unique solution est…

✅ Quand Δ = 0, la formule devient x = (−b ± 0) / 2a = −b / 2a. Et tu la connais déjà : c'est α, l'abscisse du sommet (partie 1) ! Logique : la parabole touche le sol pile par son sommet.
Récap

Ce qu'il faut retenir 📌

1. Résoudre = graphique

Les solutions de ax² + bx + c = 0 sont les points où la parabole coupe l'axe horizontal.

2. Le discriminant

Δ = b² − 4ac. Son signe donne le nombre de solutions : 2 si Δ>0, 1 si Δ=0, 0 si Δ<0.

3. La formule

Si Δ ≥ 0 : x = (−b ± √Δ) / 2a. Le ± donne les deux solutions. Si Δ = 0 : x = −b/2a (le sommet).

4. Les cas rapides

b = 0 : isole x² (± !). c = 0 : mets x en facteur, produit nul.

5. Toujours vérifier

Remplace x par ta solution dans l'équation. Et dans un problème concret, vérifie que la solution a un sens !

🌟 Mission accomplie : le ballon de la partie 1 retombe à 20 mètres, et c'est toi qui l'as calculé. La question qui a ouvert le chapitre est résolue !
