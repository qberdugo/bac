FICHE DE RÉVISION

Équations du second degré — partie 2 : Résolution  •  ax² + bx + c = 0  (a ≠ 0)

1. RÉSOUDRE, C'EST QUOI ? (VERSION GRAPHIQUE)
Résoudre ax² + bx + c = 0, c'est chercher les x pour lesquels y = 0 : les points où la parabole coupe l'axe horizontal.
Δ > 0
2 solutions
Δ = 0
1 solution (le sommet !)
Δ < 0
0 solution
2. LE DISCRIMINANT
Δ = b² − 4ac
Son signe donne le nombre de solutions :
Δ > 0 → 2  •  Δ = 0 → 1  •  Δ < 0 → 0.
Identifier a, b, c AVEC leurs signes !
3. LES SOLUTIONS (si Δ ≥ 0)
x = −b ± √Δ2a
Si Δ = 0 : une seule solution  x = −b2a  (le sommet !)
4. LA MÉTHODE EN 4 ÉTAPES
  1. 1 Identifier a, b, c (avec leurs signes !)
  2. 2 Calculer Δ = b² − 4ac
  3. 3 Signe de Δ → 2, 1 ou 0 solution(s)
  4. 4 Si Δ ≥ 0 :  x = −b ± √Δ2a
5. LES CAS RAPIDES (sans Δ !)
b = 0 : isole x².  2x² − 18 = 0 → x² = 9
→ x = 3 ou x = −3 (ne pas oublier le − !)
c = 0 : mets x en facteur (produit nul).
3x² + 6x = 0 → 3x(x + 2) = 0 → x = 0 ou x = −2
x² = nombre négatif → aucune solution.
6. EXEMPLE : x² − x − 6 = 0
a = 1,  b = −1,  c = −6
Δ = (−1)² − 4×1×(−6) = 1 + 24 = 25 > 0 → 2 solutions
√Δ = √25 = 5
x₁ = (1 − 5)/2 = −2    x₂ = (1 + 5)/2 = 3
Vérif : 3² − 3 − 6 = 0 ✓
7. LES PIÈGES À ÉVITER
  • b et c gardent leur signe :
    dans 3x² − 5x + 2, b = −5 (pas 5 !)
  • 2a au dénominateur : si a est négatif, 2a aussi !
  • x² = 4 a DEUX solutions : x = 2 et x = −2
  • Problème concret : vérifie que la solution a un sens (une distance négative se rejette… en le disant).
